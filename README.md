🐍 Build a To-Do List App Using Python!

In this video, I'll show you how to create a simple and useful To-Do List application using Python and Tkinter. This beginner-friendly project helps you learn Python programming while building a desktop app with a graphical user interface (GUI).

✨ Project Features:
- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete selected tasks
- 🧹 Clear all tasks
- 📊 Track total and completed tasks
- 🎨 Simple and user-friendly interface

🛠️ Technologies Used:
- Python
- Tkinter
- VS Code



📚 This project is perfect for Python beginners who want to practice GUI development and build practical programming projects.
